# roblox-project

A Roblox place defined as a Rojo project. It currently contains one anchored
`Part` in `Workspace`.

## Open it

* **Without installing anything:** download `build/roblox-project.rbxlx` and open
  it in Roblox Studio (File → Open from File).
* **With Rojo:** `rojo build default.project.json -o build/roblox-project.rbxlx`,
  or `rojo serve` to sync into an open Studio session.

Edit `default.project.json` to change the part (size, position, colour,
material) and rebuild.
